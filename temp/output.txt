We have more than one generator so we are using superposition to calculate voltages/currents.
Names starting with RGenZero refer to very small resistances, used during superposition.

###Processing generator VS2

First we calculate the total resistance between the generator nodes (VS2)
Rf0=R3=3Ohm=3Ohm
R1 and Rf0 connected in series so Rd0=R1+Rf0=1Ohm+3Ohm=4Ohm
R5 and Rd0 connected in parallel so Rc0=R5*Rd0/(R5+Rd0)=2Ohm*4Ohm/(2Ohm+4Ohm)=1.33Ohm
R2 and Rc0 connected in series so Rb0=R2+Rc0=4Ohm+1.33Ohm=5.33Ohm
Rb0 and R4 connected in series so Ra0=Rb0+R4=5.33Ohm+5Ohm=10.3Ohm
The total resistance is Ra0 = 10.3Ohm

Now we calculate the current on RGenZero1
We know that the voltage between VS2 nodes is 4 Volt.
All voltage generators except for VS2 have been replaced with a short circuit.
All current generators have been replaced with an open circuit.

The components Rb0 and R4 connected in series.
The voltage between this components starting and ending node is 4 Volt
Rb0 is in the voltage divider so the voltage on Rb0 is Rb0/Ra0*4 Volt = 2.06 Volt 
The current on Rb0 is the voltage on Rb0/Rb0 = 387m Amper

The components R2 and Rc0 connected in series.
The voltage between this components starting and ending node is 2.06 Volt
Rc0 is in the voltage divider so the voltage on Rc0 is Rc0/Rb0*2.06 Volt = 516m Volt

The components R5 and Rd0 connected in parallel. The voltage on Rd0 is 516m Volt because the voltage on Rc0 is 516m Volt

###Processing generator VS1

First we calculate the total resistance between the generator nodes (VS1)
Re1=R2=4Ohm=4Ohm
R4 and Re1 connected in series so Rd1=R4+Re1=5Ohm+4Ohm=9Ohm
R5 and Rd1 connected in parallel so Rc1=R5*Rd1/(R5+Rd1)=2Ohm*9Ohm/(2Ohm+9Ohm)=1.64Ohm
Rc1 and R1 connected in series so Rb1=Rc1+R1=1.64Ohm+1Ohm=2.64Ohm
R3 and Rb1 connected in series so Ra1=R3+Rb1=3Ohm+2.64Ohm=5.64Ohm
The total resistance is Ra1 = 5.64Ohm

Now we calculate the current on R1
We know that the voltage between VS1 nodes is 6 Volt.
All voltage generators except for VS1 have been replaced with a short circuit.
All current generators have been replaced with an open circuit.

The components R3 and Rb1 connected in series.
The voltage between this components starting and ending node is 6 Volt
Rb1 is in the voltage divider so the voltage on Rb1 is Rb1/Ra1*6 Volt = 2.81 Volt 
The current on Rb1 is the voltage on Rb1/Rb1 = 1.06 Amper

The components Rc1 and R1 connected in series.
The voltage between this components starting and ending node is 2.81 Volt
R1 is in the voltage divider so the voltage on R1 is Rf1/Rb1*2.81 Volt = 1.06 Volt 
The current on R1 is the voltage on R1/Rf1 = 1.06 Amper

The current on R1 is the voltage on R1/R1 = 1.06 Amper
