We have more than one generator so we are using superposition to calculate voltages/currents.
Names starting with RGenZero refer to 0 Ohm resistances, used during superposition.

## Processing generator VS2
Rd0 represents a temporary resistance with a value of 0
First we calculate the total resistance between the generator nodes (VS2)
Rc0=R1=1kOhm=1kOhm
R2 and Rc0 connected in series so Rb0=R2+Rc0=1kOhm+1kOhm=2kOhm

Ra0=Rb0=2kOhm=2kOhm
The total resistance is Ra0 = 2kOhm

Now we calculate the voltage on R1
We know that the voltage between VS2 nodes is 5 Volt.
All voltage generators except for VS2 have been replaced with a short circuit.
All current generators have been replaced with an open circuit.

The components Rb0 and Rd0 connected in series.
The voltage between this components starting and ending node is 5 Volt
Rb0 is in the voltage divider so the voltage on Rb0 is Rb0/Ra0*5 Volt = 5 Volt 

The components R2 and Rc0 connected in series.
The voltage between this components starting and ending node is 5 Volt
Rc0 is in the voltage divider so the voltage on Rc0 is Rc0/Rb0*5 Volt = 2.5 Volt 

The components R1 and RGenZero1 connected in series.
The voltage between this components starting and ending node is 2.5 Volt
R1 is in the voltage divider so the voltage on R1 is R1/Rc0*2.5 Volt = 2.5 Volt (node numbers 4 and 3)
